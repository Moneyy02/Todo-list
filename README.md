# 📝 React Todo List

A simple and interactive Todo List application built using React.  
It helps users manage daily tasks with ease.

## ✨ Features
- ➕ Add new tasks  
- ❌ Delete tasks  
- ✅ Mark tasks as completed (checkbox)  
- 🔄 Instant UI updates using React
